📱 휴대폰으로 현장 합류

현장 참여 코드
휴대폰 합류는 서버 프로젝트에서 가능합니다. 상단의 프로젝트 메뉴에서 「새 프로젝트」를 만들거나 「서버 프로젝트 열기」를 하세요. 서버는 현장모니터링_실행.bat으로 켭니다.
  1. 휴대폰을 이 PC와 같은 와이파이에 연결합니다.
  2. 카메라로 QR을 찍거나 주소를 열고, 이름과 역할(작업자/장비 운전원)을 고릅니다.
  3. 화면을 켠 채로 두면 위험 반경 경보를 받습니다.

🔧 AI 백엔드 서버 설정

다른 PC에서 서버를 켰다면 그 PC의 주소를 입력하세요. (예: http://192.168.0.5:8000)

# 서버 직접 실행
cd backend
pip install -r requirements.txt
python main.py                 # 이 PC에서만
python main.py --host 0.0.0.0  # 다른 PC 접속 허용

AI 서버 없이도 배치도 위에 장비·위험물·건물을 수동으로 배치해 모든 기능을 쓸 수 있습니다.
